# «На связи» — учебное веб-приложение

Интерактивная игра для 4 класса о негативном общении и кибербуллинге.

## Что есть в версии
- вход ребёнка по имени;
- выбор персонажа;
- 12 игровых ситуаций;
- скрытый подсчёт поведенческих стратегий;
- сохранение результатов в SQLite;
- отдельная панель педагога `/teacher`;
- сводная таблица класса;
- удаление ошибочного/тестового результата;
- адаптивный интерфейс для телефона.

## Важная методическая оговорка
Приложение НЕ диагностирует личность ребёнка и не делает выводов «добрый/агрессивный/будет травить».
Оно показывает только стратегии, выбранные в конкретных игровых ситуациях.

## Запуск на компьютере
1. Установить Python 3.11+
2. В папке проекта:
   pip install -r requirements.txt
3. Задать пароль педагога:
   - Windows PowerShell: `$env:TEACHER_PASSWORD="ваш_пароль"`
   - macOS/Linux: `export TEACHER_PASSWORD="ваш_пароль"`
4. Запустить:
   uvicorn app:app --reload
5. Открыть:
   http://127.0.0.1:8000
   Панель педагога:
   http://127.0.0.1:8000/teacher

Если пароль не задан, тестовый пароль: school2026

## Как получить общую ссылку
Проект подготовлен для деплоя на Render/Docker-подобный хостинг.
Нужно разместить папку проекта в GitHub и создать Web Service из Dockerfile.
Для реального использования обязательно задайте свой `TEACHER_PASSWORD`.
